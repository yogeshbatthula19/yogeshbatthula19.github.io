The Problem

A fragile monolith limiting growth

The client's existing platform was a coupled PHP monolith struggling under peak traffic. Checkout failures, slow load times, and no mobile-optimised experience were costing revenue every day.

  • Checkout timeout rate of 12% under normal load
  • No real-time stock visibility for warehouse staff
  • Manual order processing adding 2–3 hours per day
  • Zero API surface for future mobile or third-party integrations

The Solution

Microservices re-architecture, built for scale

I designed and built a decoupled microservices architecture with independent services for auth, inventory, orders, and payments — communicating via a message queue, all deployed on AWS ECS behind an Application Load Balancer.

Independent deployment Horizontal scaling Event-driven updates Circuit breakers

Process

How the project unfolded

Phase 01 — Discovery

Stakeholder interviews & system audit

Worked with the client's team to map all existing business logic, third-party integrations, and pain points. Produced a service dependency diagram and identified the highest-risk areas for migration.

Phase 02 — Architecture

Service design & data modelling

Defined service boundaries, API contracts (OpenAPI 3), and database schemas. Chose MongoDB for product/order data and Redis for session caching and pub/sub messaging between services.

Phase 03 — Build

Iterative development with CI/CD

Built and shipped each service incrementally behind a feature flag, enabling the team to test in production without risk. All services were containerised with Docker and deployed via GitHub Actions → AWS ECR → ECS.

Phase 04 — Launch & Optimise

Zero-downtime migration & performance tuning

Used a strangler-fig migration pattern to cut traffic over from the old platform with zero downtime. Post-launch profiling reduced average API response time from 420 ms to 130 ms through query optimisation and caching.

Tech Stack

Built with purpose, not hype

Frontend

  • React 18 — component-driven UI with code splitting
  • TypeScript — end-to-end type safety
  • Tailwind CSS — utility-first styling, zero unused CSS in prod
  • React Query — server state management & caching

Backend

  • Node.js + Express — API gateway & service layer
  • MongoDB Atlas — flexible document store for products & orders
  • Redis — session caching & event pub/sub
  • Stripe API — PCI-compliant payment processing

Infrastructure

  • AWS ECS (Fargate) — serverless container orchestration
  • AWS CloudFront — global CDN with edge caching
  • Docker — reproducible build & deployment environments
  • GitHub Actions — automated CI/CD pipeline
